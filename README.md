# P8105 Homework 4

Problem 2 is an interactive flexdashboard built from the Instacart data in `p8105.datasets`.

- Dashboard: https://hytong-claudine.github.io/instacart.html
- Source: `p8105_hw4_hct2116.Rmd`

Open `p8105_hw4_hct2116.Rproj` in RStudio to work on the assignment. To render the dashboard, install `tidyverse`, `p8105.datasets`, `plotly`, and `flexdashboard`, then knit the R Markdown file.
